# sequential-vs-random

From the repository root:

```bash
python3 scripts/run_suite.py sequential-vs-random
python3 scripts/plot_results.py sequential-vs-random
```

See [experiment methods](../README.md) for variables, measurements, interpretation, and DRAM mapping caveats. Outputs go to `results/`, which is excluded from Git; generated plots go to `assets/plots/`.
